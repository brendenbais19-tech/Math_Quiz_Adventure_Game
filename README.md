# 🎮 Interactive Math Quiz Game (Addition)

An interactive, responsive, and web-based Math Quiz Game designed for practice and learning addition across 100 dynamic levels. Powered by HTML5, Tailwind CSS, JavaScript, and Web Audio API synthesis.

Developed by **YuhTwin**.

---

## ✨ Features

- 🏆 **100 Dynamic Levels:** Progression from simple additions to advanced multi-digit challenges.
- 🧮 **100 Questions Per Level:** Generates fresh, non-repeating math questions dynamically.
- 🔄 **Smart Anti-Repetition Engine:** Prevents exact and inverse duplicates (e.g., $4 + 1$ and $1 + 4$) from repeating consecutively.
- 💾 **Real-Time Auto-Save:** Automatically saves player profiles, unlocked levels, stars, and total scores to `localStorage`.
- 🎵 **8-Bit Synth Audio (BGM & SFX):** Energetic, royalty-free background music and sound effects powered by the Web Audio API (no external `.mp3` downloads required).
- 🎨 **Custom Player Profiles:** Choose custom player names and 10+ emoji avatars.
- 📱 **Responsive Design:** Optimized for mobile phones, tablets, and desktop browsers using Tailwind CSS.
- 📊 **End-of-Level Scoreboard:** Displays detailed accuracy percentage and star ratings upon completion.

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Ensure the main file is named `index.html`.
3. Open `index.html` directly in any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox).
4. No web server or external database required!
